# 三、★ 一个我必须指出的**真实风险**

**我们给 space 加 `kokoaSessionId`，会不会被 Zen 的同步带走？**

```
已知：
  · ADR-019 证明 space 加字段会自动持久化（sessionstore）
  · 但 src/zen/sync/（1987 行）我们【没读】
  · 如果 Zen 的同步会把 space 数据同步到云端，
    那 kokoaSessionId 也会被同步 —— 这可能：
      a) 泄漏我们的会话 id 到 Zen 的同步服务
      b) 在多设备间产生不一致
      c) 触发我们没预期的行为
```

**这条在实施 ADR-019 之前必须先查清。**
我之前写的 `workitem-workspace-session-binding.md` 里**没有提这个风险** ——
那是个疏漏（当时只读了 spaces 与 sessionstore，没看 sync）。
